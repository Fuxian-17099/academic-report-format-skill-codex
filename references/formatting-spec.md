# 格式规范 1.0.0

## 来源和优先级

实际解析原报告 styles、numbering、document、settings、7 个 header、6 个 footer、包关系及媒体/嵌入对象清单。原始 SHA-256 与脱敏的具体 XML 参数见 `source-format-evidence.json`。原文共 923 段、16 表、3 节、2 个原生 OMML 对象；另含 MathType 对象/域。原编号包含多个 abstractNum/num、样式链接及直接格式覆盖，存在隐藏编号段。原文中很多正文使用 Normal 加直接格式，而不是 正文_改。

用户明确要求高于样本：正文必须正文_改，标题 16/14/12 pt 并全部加粗、编号 TNR 粗体；参考文献标题宋体；图表公式采用可更新域。清洁模板重新构建源格式角色，不复制源正文和不必要的包部件。没有保留样本中隐藏的编号辅助段、旧项目页眉和 MathType 私有 OLE。

## 正文与标题

| 角色 | 中文 / 西文 | 字号和字重 | 间距、对齐 |
|---|---|---|---|
| 正文_改 | 宋体 / Times New Roman | 12 pt，常规 | 固定20 pt，首行2字符，段前后0，两端对齐 |
| 章 Heading 1 | 黑体 / Times New Roman | 16 pt，粗体 | 段前12、后3 pt，固定20 pt，居中，章前分页 |
| 节 Heading 2 | 黑体 / Times New Roman | 14 pt，粗体 | 段前18、后6 pt，固定20 pt，左对齐 |
| 小节 Heading 3 | 黑体 / Times New Roman | 12 pt，粗体 | 段前12、后6 pt，单倍，左对齐 |
| 参考文献标题 | 宋体 / Times New Roman | 16 pt，粗体 | 居中，段前12、后3 pt，不编号，一级大纲 |
| 参考文献条目 | 宋体 / Times New Roman | 10.5 pt，常规 | 至少20 pt，悬挂525 twips，段前后0，两端对齐 |

正文样式的原 firstLineChars=200、firstLine=200，字符缩进优先；引擎同时将物理 fallback 修正为480 twips，即12 pt的2字符。段前后未在源正文样式和 Normal 中指定，解析继承后采用0。两端对齐继承源 Normal。中文宋体来自源主题/正文混排及用户要求，模板改为显式 rFonts。

原章实际用 Title（a0），间距240/60 twips；原节用“一级标题”（a），360/120；原小节用“二级标题_改”（a2），240/120，单倍。采用这些实际角色的间距，避免按误导的样式名称映射。字号和粗体按用户要求覆盖。原参考文献样式悬挂250，但实际条目普遍直接覆盖525，因此采用525。

## 图表、公式和封面

图题取源 Caption 角色，10.5 pt、居中、固定20 pt、前后0；表题取源正文题注习惯，12 pt，同样居中。图题下置、表题上置。图片用独立样式居中、单倍行距以免固定行高裁切；与图题 keepNext。表格优先按用户要求三线表，表头10.5 pt粗体，正文10.5 pt；顶底1.5 pt，中间表头底线0.75 pt，无竖线，重复表头、不拆单行。原表格多用源 Table Grid 派生样式，并不全部是三线表，此项遵循用户明确偏好。

独立公式单倍行距，页面正文宽度中点中心制表位、右边界右对齐制表位，公式居中，编号 `(章.序)` 靠右。较宽公式必须视觉检查或拆分，不缩成图片。

封面保留源“机构—报告类型—题目—信息项”的纵向构成：机构24 pt华文行楷，报告类型36 pt楷体，题目/信息18 pt黑体；西文均TNR。源“楷体_GB2312”改为本机可用楷体。机构、姓名、学号、教师、课程及日期只从输入读取；机构默认空。封面空行布局转换为样式间距以适配可变题目，不保留原样本个人字段值。

目录为 TOC 域，1–3级及参考文献标题，由大纲级别识别。TOC 1/2/3分别14/14/12 pt宋体、西文TNR，行距20 pt；源三级有更深缩进，模板采用5/10/42 pt层级缩进和右侧点引导页码。Word刷新后应逐页检查。
