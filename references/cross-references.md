# 可更新交叉引用

图：`图 { STYLEREF 1 \\s }-{ SEQ Figure \\s 1 } 题注`；表用独立Table序列；公式 `({ STYLEREF 1 \\s }.{ SEQ Equation \\s 1 })`。文献用独立SEQ Reference，不按章重置。这里花括号表示Word域，生成器写的是begin/instrText/separate/end的真实复杂域，不是普通花括号字符串。

对象ID全局唯一，派生书签名为AR_加SHA-256前24位；书签有效且短于40字符。正文 `[[ref:id]]` → `REF bookmark \\h`，`[[cite:id]]` → 方括号中的REF。图表和公式的书签包住整个编号字段组合，因此跨章节引用仍含章号。所有ID在写正文前注册，支持向前引用；不存在或重复ID使生成立即失败。

无Python预计算的假编号缓存。初次生成域缓存为空，Word更新后得到真实值。新增/删除/排序参考文献建议改JSON后重生成；直接在Word中移动需连同书签移动，删除被引用对象后校验应FAIL。Word更新脚本遍历story、TOC，重复刷新3次并Repaginate，再保存和可选导出PDF。脚本新开隐藏Word实例、禁宏，不关闭用户已有Word。

手动更新：正文Ctrl+A、F9，右键目录“更新整个目录”；页眉页脚域也需更新。Web版可能保留域但不能完整编辑/更新，最终校对使用桌面Word。图表重排、章次变化和文献顺序变化都应重跑校验与Word更新。

格式化既有静态文档时，不凭号码猜链接，先提取题注和引用建立用户可核对的ID映射，再用JSON重生成或逐处转换。保守格式化脚本只保留现有有效域，静态引用会由校验报告失败。
